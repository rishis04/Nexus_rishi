## 1. Project Overview

This project is a privacy-preserving, on-device browser perception and action-validation system for lightweight browser agents.

The architecture is built around a strict privacy boundary:

**Browser Page → DOM/ARIA Perception + Visual Perception → PII Detection/Redaction → Sanitized Observation → BrowserOS/Agent → Action Contract → Action Validator → Browser Action**

The privacy pipeline is authoritative. Agent components must consume sanitized observations rather than raw personal data.

20. Design Principles
Privacy first
Sensitive data is processed locally wherever possible.
Redaction before exposure
The agent receives sanitized observations rather than raw page state.
Fail closed
If action validation cannot establish that an action is safe, reject it.
Separation of concerns
Perception ≠ Privacy ≠ Agent ≠ Action Execution
Deterministic behavior
PII classification and action validation should be deterministic and testable.
Modular detectors
New PII types can be added through the detector registry without redesigning the complete privacy pipeline.
Regression protection
Privacy-critical face masking is protected by dedicated regression tests.
Agent independence
The privacy layer should not depend on a particular AI model or browser-agent implementation.
